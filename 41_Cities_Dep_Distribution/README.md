# 41-City Presale Supervision Fund Dep Tool

This package contains a standalone offline interactive model for exploring Dep opportunity costs associated with presale supervision funds across 41 cities.

## Entrances

- `dep_model_41_cities_zh.html` — Chinese interface.
- `dep_model_41_cities_en.html` — English interface, calculation-equivalent to the Chinese interface.

Open either HTML file directly in a modern web browser. No installation, server, external data file, or network connection is required. Baseline data and the calculation logic are embedded in each page.

The package is intentionally limited to the two user-facing entrances and this README. It does not include development scripts, logs, raw workbooks, private paths, caches, experiment records, or unpublished internal documentation.

Changing parameters affects the displayed sensitivity analysis only; the pages do not write back to external files.
