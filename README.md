# 4_PMC_mix
Policy Consistency without Operational Equivalence: Evidence from China’s Presale-Fund Supervision

# Abstract
Uniform regulatory frameworks are increasingly used to protect buyers in housing finance, yet outcomes diverge once cities write the operating rules. China’s presale-fund supervision requires all presale receipts to enter supervised accounts and allows disbursement against construction progress. Each city decides how much stays behind, which milestones release funds, and when supervision ends. Comparative research scores such rules with text-based consistency indices, and this study asks whether they track how supervision operates. We develop two metrics measure of the supervision bundles of 41 Chinese cities which were still valid in May 2024. For the textual measure, we identify ten coding dimensions and compute four consistency indices: binary, frequency-weighted, term-frequency, and semantic. For the operational measure, we code five attributes of the release clauses. We then compared textual distance with rule distance across all 820 city pairs. Textual distance carried almost no information about rule distance, and the rank correlation was near zero for every index. A city-level permutation test further shows that the design would have detected even a weaker association than those observed. The five attributes produced no single ordering of stringency. Only the term-frequency index improved prediction of rule-implied financing exposure; the semantic index did not. The design is predictive and does not identify causal effects. Consistency scores alone cannot establish that two cities supervise presale funds alike.
